# Tripami for Claude

Read your shared trips and save plans to your Tripami itinerary. This package includes shared trip-management workflows, the Tripami icon, and a remote HTTP MCP connection to https://api.tripami.io/mcp.

For Claude directory submission, extract this bundle into the root of a dedicated GitHub repository and submit that repository at https://claude.ai/directory/manage/new. The directory currently accepts a GitHub-hosted plugin bundle; this ZIP is its portable source artifact. Connect Tripami when prompted and sign in with the same account used in the mobile app. Ask to show your upcoming trips first. Before saving plans, provide the trip, date, start time, end time, and time zone; Claude should ask for anything missing.

This package contains no credentials. Existing account access remains subject to OAuth authorization. Icon rendering depends on the Claude surface and version. This package has not been uploaded, submitted, approved or published. Review cases, demo guidance and remaining submission requirements are supplied alongside the archive, not as credentials inside it.
